# La Torre del Caballero

Juego de plataformas 2D hecho en Unity. Hay que subir la torre hasta arriba
sin caerse, esquivando a los enemigos y recogiendo monedas.

## Niveles

- **Nivel 1**: la torre del castillo, con demonios voladores.
- **Nivel Niebla**: una niebla mortal sube desde abajo y te persigue,
  con calaveras de fuego.

## Controles

| Acción | Tecla |
|---|---|
| Moverse | A / D o flechas |
| Saltar | Espacio |
| Atacar | F o clic izquierdo |
| Pausa | Esc |
